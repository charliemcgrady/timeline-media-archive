### Add Gigapixel Photo Workflow

This is the source code for a lambda function which processes gigapixel photos.

### Steps to generate gigapixel assets

- Clone https://github.com/openzoom/deepzoom.py
- Generate Deep Zoom assets (for satellite images, use https://github.com/charliemcgrady/cloudless-mosaic). Modify the source in the python code to be the JPG you want to giga'fy.
- Determine what the gigapixel key should be for these assets. I normally use the filename generate by Lightroom.
- Create a folder with the name of the gigapixel key. This folder should contain the original file (named gigapixelKey.jpg) and the assets generated by Deep Zoom.
- Zip this folder and upload via the UI!
